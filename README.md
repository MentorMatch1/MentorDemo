# MentorDemo

## What is MentorDemo

-Mentor Demo was the first conceptualization of the project while starting the initial talks with the Mentor Program at University of Alberta. It was a template application to show them what we could possibly provide for them. As the project continued on with further meetings the MentorDemo application became unused to focus on tailoring the Project to be specifically for the Science Mentorship Program. This is mostly for viewing Purposes. Public Key for this is disabled and unusable.
